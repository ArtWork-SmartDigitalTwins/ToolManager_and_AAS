AAS Generator
=============

Run:      double-click start.bat
Stop:     close the console window (or Ctrl+C)
Open:     http://localhost:4100  (opens automatically)

First run asks for your Anthropic API key and saves it to .env.
To change the key or port later, edit .env (see .env.example).

Requirements: none if the "runtime" folder contains node.exe.
Otherwise install Node.js 18+ (https://nodejs.org).

Sharing this folder: delete .env first, so your API key is not passed on.
The recipient will be asked for their own key on first start.
